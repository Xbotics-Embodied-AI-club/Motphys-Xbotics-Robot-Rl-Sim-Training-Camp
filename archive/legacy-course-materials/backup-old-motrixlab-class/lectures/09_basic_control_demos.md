# 09 基础控制 Demo 讲解：倒立摆 / 单摆 / 双连杆

## 本章目标
- 了解经典控制任务的特点
- 理解基础 RL 训练案例的分析方法
- 建立从简单到复杂的学习阶梯

## 一、为什么先学基础控制任务
倒立摆、单摆、双连杆这类任务，是强化学习和控制领域最经典的入门案例。它们的共同特点是：
- 任务结构清晰
- 状态和动作规模较小
- 便于观察训练效果
- 适合学习基本概念

## 二、倒立摆
倒立摆的核心目标是保持系统平衡。它非常适合讲解：
- 平衡控制
- 状态反馈
- 稳定性维持
- 奖励设计的基本逻辑

## 三、单摆
单摆任务比倒立摆稍微直观一些，但它仍然能很好地说明连续控制问题。通过单摆任务，可以理解：
- 如何从任意初始状态回到目标状态
- 如何通过奖励鼓励接近稳定点
- 如何观察策略是否学会控制摆动

## 四、双连杆
双连杆系统比前两个任务更复杂，因为它涉及多个关节和耦合运动。它适合用来讲：
- 多自由度系统
- 更复杂的状态空间
- 更丰富的控制行为

## 五、这些任务的教学意义
基础控制任务的价值在于，它们能帮助学习者快速建立对 RL 的直觉：
- 智能体如何根据状态选择动作
- 奖励如何引导策略改进
- 训练结果如何从失败到稳定逐步变化

## 六、总结
这类 Demo 虽然简单，但它们是理解整个平台的基础。只有先把小任务看懂，后面再看机械臂、机器人行走和抓取任务时，才会更容易理解。
