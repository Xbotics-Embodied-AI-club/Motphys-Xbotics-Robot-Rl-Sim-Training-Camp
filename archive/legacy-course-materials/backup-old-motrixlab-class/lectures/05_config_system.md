# 05 配置系统：环境配置与训练配置怎么协作

## 本章目标
- 理解环境配置和训练配置的分工
- 明白配置如何影响实验行为
- 学会从配置角度阅读项目

## 一、为什么需要配置系统
强化学习实验通常会反复修改参数，例如：
- 训练步数
- 学习率
- batch size
- 奖励权重
- 仿真步长
- 随机噪声

如果这些参数直接写在代码里，实验会很难维护。配置系统的作用，就是把这些参数结构化管理起来。

## 二、环境配置 `EnvCfg`
`EnvCfg` 主要负责环境层面的配置，例如：
- 物理仿真相关参数
- 任务行为相关参数
- reset 和终止条件
- 观测与动作相关设定

它决定的是“环境如何运行”。

## 三、训练配置 `RLCfg`
`RLCfg` 主要负责训练算法相关参数，例如：
- 网络结构
- 学习率
- 训练轮数
- batch size
- 优化器相关设置

它决定的是“模型如何学习”。

## 四、两类配置如何协作
环境配置和训练配置看起来属于不同领域，但它们在训练中必须协同工作：
- 环境配置保证任务定义正确
- 训练配置保证学习过程稳定
- 两者共同决定最终实验效果

## 五、配置管理的优势
配置系统带来的好处包括：
- 参数统一管理
- 实验更容易复现
- 修改更安全
- 支持继承和覆盖
- 便于切换不同实验版本

## 六、总结
配置系统是 MotrixLab 这类工程化项目的重要基础。它把“怎么训练”和“训练什么”分开管理，让实验更清晰、更可控。
