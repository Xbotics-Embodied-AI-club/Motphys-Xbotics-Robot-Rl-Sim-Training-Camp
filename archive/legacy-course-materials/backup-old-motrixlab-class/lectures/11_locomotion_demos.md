# 11 运动机器人 Demo 讲解：Walker / GO1 / Humanoid

## 本章目标
- 了解运动控制任务的特点
- 理解复杂机器人任务的训练难点
- 学会从行走类案例中看出平台能力

## 一、为什么行走任务很重要
行走是机器人强化学习中最经典也最具代表性的任务之一。相比基础控制任务，行走任务要求智能体在复杂接触、平衡、速度控制和姿态稳定之间找到平衡。

## 二、Walker 类任务
Walker 通常用于展示基础双足或类人行走能力。它强调：
- 重心稳定
- 步态协调
- 连续推进
- 避免摔倒

## 三、GO1 类任务
GO1 属于四足机器人任务，通常更强调：
- 多腿协调
- 复杂地形适应
- 运动连续性
- 更强的鲁棒性

## 四、Humanoid 类任务
人形机器人任务更复杂，因为其自由度更多、控制要求更高、稳定性更难维持。它往往是最能体现训练、奖励和仿真综合能力的案例之一。

## 五、这类任务的共同难点
- 接触复杂
- 稳定性要求高
- 奖励设计敏感
- 对仿真精度更依赖
- 容易出现训练不稳定

## 六、总结
运动机器人 Demo 是整个课程中最能体现平台能力的部分。它们不仅能展示算法效果，也能帮助学习者理解复杂机器人任务是如何逐步构建和训练出来的。
