## 第 1 模块：强化学习基础概念（录播 1.5 小时）

### 第 1 节：什么是强化学习（30 min）
- AI 三大范式对比：监督学习 / 无监督学习 / 强化学习
- RL 核心要素：智能体、环境、状态、动作、奖励
- 典型应用：游戏 AI、机器人控制、自动驾驶
- 为什么机器人领域离不开 RL？

### 第 2 节：马尔可夫决策过程 MDP（30 min）
- 状态空间与动作空间（离散 vs 连续）
- 奖励函数：信号的设计决定了智能体学什么
- 折扣因子 γ：短视 vs 远见
- 策略（Policy）和价值函数（Value Function）的关系

### 第 3 节：探索与收敛（30 min）
- Exploration vs Exploitation 的核心矛盾
- ε-greedy 策略
- Q-Learning 入门（GridWorld 演示）
- 从表格到神经网络：DQN 的诞生动机
- 连续控制任务为什么需要策略梯度方法

---

## 第 2 模块：PPO 算法精讲（录播 1.5 小时）

> MotrixLab 默认使用 PPO，本模块重点讲透这一算法

### 第 4 节：策略梯度方法（30 min）
- Policy Gradient 核心思想：让好动作概率更高
- REINFORCE 算法推导（直觉版，不堆数学）
- 方差问题与 Baseline 技巧
- Actor-Critic 架构：策略网络 + 价值网络

### 第 5 节：PPO 算法详解（40 min）
- Importance Sampling：为什么可以重复使用旧数据
- Clip 机制：如何防止策略更新步子太大
- PPO 的训练循环：收集数据 → 计算优势 → 多步更新
- 连续动作空间：高斯分布输出的策略网络
- PPO 为什么成为机器人 RL 的主流选择

### 第 6 节：训练稳定性与调参（20 min）
- 关键超参数：学习率、clip ε、GAE λ、mini-batch
- 奖励归一化与观测归一化的重要性
- 如何看训练曲线判断是否收敛
- SKRL 与 RSLRL 框架简介（MotrixLab 支持的两个框架）

---

## 第 3 模块：MotrixLab 平台入门与训练流程（录播 1.5 小时）

### 第 7 节：课程导论与平台定位（20 min）
- MotrixLab 能做什么：机器人强化学习仿真、训练、验证与案例复现
- MotrixLab 的定位与应用场景
- 机器人强化学习平台的核心价值
- 课程学习路径与目标
- 安装环境

### 第 8 节：基础框架总览与核心组件（35 min）
- MotrixLab 的整体分层设计
  ```
  用户接口层       ← scripts / 命令行入口
  训练算法层       ← motrix_rl / PPO 算法与训练配置
  环境实现层       ← motrix_envs / 任务定义、环境逻辑、奖励函数
  物理仿真层       ← MJCF 模型、仿真参数、机器人资产
  ```
- 各层之间的关系与职责划分
- **EnvCfg**：环境配置类，定义仿真参数、episode 长度、MJCF 模型文件
- **Env**：环境实现类，负责观测、动作、任务逻辑和终止条件
- **Reward**：在 `_compute_reward()` 中实现奖励计算
- **RLCfg**：训练配置类，定义算法、网络、学习率、batch 等训练参数
- EnvCfg 与 RLCfg 的分工：环境描述任务，训练配置描述学习过程

### 第 9 节：注册系统、训练流程与 Demo 分析方法（35 min）
- 注册系统的作用：让新任务被框架自动识别
- 环境配置、环境实现、RL 配置的注册方式
- `@registry.env()` 一行接入新环境
- 数据流：`train.py` → 查找注册配置 → 创建环境 → PPO 训练 → 保存模型
- 运行第一个示例：`python scripts/train.py --env cartpole`
- 用 `play.py` 和 `view.py` 可视化训练结果
- 分析一个 Demo 的通用方法：
  1. 任务目标是什么
  2. 观测空间包含哪些信息
  3. 动作空间控制什么量
  4. 奖励函数如何引导学习
  5. 终止条件如何定义失败或成功
- 如何从 Demo 中提炼可复用的环境设计思路

## 第 4 模块：实战——读懂 Demo、改奖励、训练机器人智能体（录播 1 小时）

### 第 10 节：基础控制 Demo 讲解（20 min）
- 选取 2-3 个平台内置示例对比演示：
  - **倒立摆**：经典连续控制，适合验证环境
  - **单摆 / 双连杆**：小规模状态空间与动作空间分析
  - **机器狗**：运动控制入门
- 分析不同任务的观测空间 / 动作空间 / 奖励设计差异
- 展示训练曲线与最终表现对比

### 第 11 节：机械臂、抓取与运动机器人 Demo 讲解（25 min）
- **机械臂到达 / 抓取任务**：机械臂控制任务的核心难点
- 抓取、到达、操作类任务的奖励设计
- 接触控制与精细动作学习
- **Walker / GO1 / Humanoid**：机器人行走任务的共性与差异
- 稳定性、接触、平衡与协调控制
- 复杂运动任务中的训练挑战

### 第 12 节：调优、问题排查与进阶路线（15 min）
- 常见训练失败原因与排查方法
  - 奖励一直为 0（稀疏奖励）
  - 策略早熟（陷入局部最优）
  - 物理仿真不稳定（时间步长设置）
- TensorBoard 监控要看哪些指标
- GPU 加速训练（SKRL 的 JAX/PyTorch 后端切换）
- 如何自己改 Demo、调奖励、做新任务
- MotrixLab 更多示例推荐：四足机器人、Shadow Hand、Unitree GO1
- 进阶方向：SAC（样本效率更高）、MARL（多智能体）、Sim-to-Real
- 社区与资源
